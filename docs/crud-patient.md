# CRUD Patient

## Identifikasi Masalah
User perlu UI untuk menampilkan data pasien

## Penyelesaian
Perlu dibuat UI sistem manajemen data pasien yang terdiri dari create, read, update, dan delete

## Checklist Kebutuhan
- [ ] UI fitur read menampilkan data pasien berupa tabel
- [ ] UI modal untuk fitur create menambah data pasien
- [ ] UI modal untuk fitur update mengubah data dalam bentuk modal
- [ ] UI pop up konfirmasi untuk fitur delete sebelum benar-benar dihapus

##  Catatan Extra
Kolom yang dibutuhkan adalah nama, nomer rekam medis, kamar, tanggal lahir, gender, status fase, aksi
